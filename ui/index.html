从浏览器扩展导入

在已登录的模型网页打开配套扩展，点击导出，再在这里选择 JSON 文件与上方目标模型。扩展可包含当前网页的 localStorage，适用于部分 DeepSeek / Qwen 登录方式。

  1. Chrome / Chromium / Brave / Edge：在扩展管理页启用开发者模式，加载项目中的 browser-extension/chromium 文件夹。
  2. Firefox：打开 about:debugging#/runtime/this-firefox，临时载入 browser-extension/firefox/manifest.json。
  3. 进入目标模型的 HTTPS 网页，在扩展中导出，再点击“导入登录文件”。JSON 包含登录会话，请妥善保管并在导入后删除不再需要的副本。

只同步 Cookie 与受支持的 localStorage；浏览器容器、分区会话及其他存储可能无法迁移。模型仍要求登录时，请在应用网页完成验证。

关于网页模式

GLM / Qwen 复用当前页面以保留手动选择的模型；其他站点按适配器准备新会话，并发送完整逻辑对话；左侧对话历史连续保留。网页 DOM 会变化，提取的 Markdown 保留主要结构，但不保证与网站原生导出完全一致。

若网页要求验证码、重新登录或出现额度限制，请在右侧手动处理。看到“请在网页重试”时，请保持原会话并点击本轮重试按钮；输入尚未提交时请核对后手动发送，程序会在恢复时限内继续等待。
